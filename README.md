# 🤖 AI Crypto Assistant

**An intelligent assistant that provides real-time insights and summaries about the top 50 cryptocurrencies.**

Whether you're a crypto enthusiast, investor, or just curious about digital assets, this assistant helps you stay informed and updated — all powered by AI.

---

## 🚀 Features

- 📈 **Live Price Updates** – Instantly fetch the latest price for any top 50 cryptocurrency via the Coingecko API.
- 🧮 **Market Cap and Rank** – See how each coin stacks up globally, with up-to-date market capitalization and ranking.
- 📰 **Recent News** – Get a snapshot of what's happening in the crypto world (demo currently shows mocked news for testing).
- 🧠 **Smart Summaries** – Automatically generate clear, human-like summaries using a GPT-powered model.

The assistant combines structured market data with natural language understanding to give you fast, relevant, and easy-to-read insights.

## 📦 Installation

To get started, make sure you have Python installed (3.9+ recommended), then follow these steps:

```bash
# Clone the repository (replace with your repo link if needed)
git clone https://github.com/your-username/ai-crypto-assistant.git
cd ai-crypto-assistant

# Install required Python packages
pip install -r requirements.txt
```

Once installed, you can launch the assistant script or integrate it into your existing application.
